# OrSAT — онлайн-опросник

Опросник оральных навыков и глотания у детей со СМА (0–24 мес.) для родителей и врачей.
Страница работает без интернета и без сервера: всё хранится только на устройстве.

## Команды

```
npm install      # один раз
npm test         # проверка логики подсчёта
npm run build    # проверка типов и сборка dist/orsat.html
```

Готовая страница — `dist/index.html` (для хостинга) и её копия `dist/orsat.html` (чтобы переслать файлом).
TypeScript превращается в JavaScript при сборке, поэтому на хостинге нужен только этот файл — сервер с Node.js не нужен.

## Публикация на GitHub Pages

1. Создайте на GitHub репозиторий (на бесплатном аккаунте Pages работает только с публичными репозиториями — код и тексты будут видны всем).
2. Отправьте туда этот проект в ветку `main`.
3. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Каждый push в `main` запускает `.github/workflows/pages.yml`: установка, тесты, сборка, публикация.
   Если тесты не прошли, сайт не обновится.
5. Адрес сайта — `https://<имя-аккаунта>.github.io/<имя-репозитория>/`. Его видно во вкладке **Actions** у последнего запуска и в **Settings → Pages**.

Страница помечена `noindex`, поэтому поисковики не должны её показывать: открыть её смогут те, кому вы дадите ссылку.

## Где что лежит

- `src/content.ts` — пункты, ответы, уровни и таблица границ (дословно из бланка «Опросник Or-Sat final»).
- `src/info.ts` — тексты информационной страницы и инструкции для родителя и врача.
  Источник каждого утверждения помечен: `[RU]`, `[ORIG]` или `[GEN]` — общие сведения, их нужно согласовать с авторами.
- `src/scoring.ts` — возраст, возрастные группы, подсчёт баллов и уровень.
- `src/app.ts` — экраны и навигация.
- `src/styles.css` — стили: телефон (Galaxy S24, 360 px), светлая и тёмная тема, печать.

Места, которые ждут ответа авторов, помечены в коде комментарием `ВОПРОС АВТОРАМ N`.
